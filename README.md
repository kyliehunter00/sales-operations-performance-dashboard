# Sales Operations Performance Dashboard

## Project Overview
An Excel-based sales operations analysis using fictional sales transaction data to evaluate revenue performance, KPI attainment, and operational trends.

## Tools Used
- Microsoft Excel
- Excel formulas and charts
- CSV data analysis
- GitHub for project documentation

## Key Findings
- Total Net Revenue: $166,623
- Revenue Target: $164,500
- Target Attainment: 101.3%

## Business Value
This project demonstrates how sales operations teams can monitor performance, identify trends, and support data-driven decisions.

## Data Disclaimer
All data in this project is fictional and used for educational and portfolio purposes.
